### 1.3 核心概念

- **Role**: 玩家扮演的身份（如 Jackal, Medic, Jester）
- **Modifier**: 附加到玩家身上的全局效果（如 Bloody, Mini, Chameleon）
- **CustomRPC**: 通过 Among Us 原生 RPC 通道 (ID 128) 发送的自定义网络消息
- **RemoteProcess<T>**: 基于 Reactor 的类型安全 RPC 封装
- **Harmony Patch**: 通过修改 IL 字节码注入到游戏中
- **CustomOption**: mod 的自定义游戏设置项

## 2. 插件入口与初始化

### 2.1 Main.cs — TheOtherRolesPlugin

```csharp
[BepInPlugin(Id, "TheOtherRolesVersion", VersionString)]
[BepInDependency(SubmergedCompatibility.SUBMERGED_GUID, BepInDependency.DependencyFlags.SoftDependency)]
[BepInProcess("Among Us.exe")]
[ReactorModFlags(Reactor.Networking.ModFlags.RequireOnAllClients)]
public class TheOtherRolesPlugin : BasePlugin
{
    public const string Id = "me.eisbison.theotherroles";
    public const string VersionString = "1.0.0";

    public Harmony Harmony { get; } = new Harmony(Id);
    public static TheOtherRolesPlugin Instance;

    public override void Load()
    {
        Logger = Log;
        Instance = this;

        // 1. Beta 版本检查
        _ = Helpers.checkBeta();

        // 2. 加载多语言
        ModTranslation.Load();

        // 3. 绑定配置文件
        DebugMode = Config.Bind("Custom", "Enable Debug Mode", "false");
        Ip = Config.Bind("Custom", "Custom Server IP", "127.0.0.1");
        Port = Config.Bind("Custom", "Custom Server Port", (ushort)22023);

        // 4. 注册所有 Harmony 补丁
        Harmony.PatchAll();

        // 5. 加载 Reactor RPC 系统（自动扫描 [TORRPCHolder] 标记的类）
        RemoteProcessBase.Load();

        // 6. 初始化各子系统
        CustomOptionHolder.Load();       // 加载所有选项
        CustomColors.Load();             // 自定义颜色
        AssetLoader.LoadAssets();        // 加载资源
        TORAchievementManager.LoadAchievements();  // 成就系统
        EventDetail.Load();              // 事件详情
        TranslatableTag.Load();          // 翻译标签
        Patches.ClientOption.Load();     // 客户端选项

        // 7. 场景加载回调：每帧场景加载时创建 TORGUIManager
        SceneManager.sceneLoaded += (scene, loadMode) =>
        {
            new GameObject("TORManager").AddComponent<TORGUIManager>();
        };
    }
}
```

### 2.2 初始化顺序总结

1. `BasePlugin.Load()` 被 BepInEx 调用
2. `Harmony.PatchAll()` — 扫描所有 `[HarmonyPatch]` 并应用补丁
3. `RemoteProcessBase.Load()` — 扫描所有 `[TORRPCHolder]` 类，注册 RPC
4. `CustomOptionHolder.Load()` — 绑定所有 `ConfigEntry`，创建 UI 选项
5. `AssetLoader.LoadAssets()` — 从程序集嵌入资源加载 Sprite/音效
6. `SceneManager.sceneLoaded` — Unity 场景加载回调，创建 GUI 管理器

### 3.3 RoleBase<T> — CRTP 泛型基类

```csharp
// TheOtherRoles.cs - 使用 CRTP 模式
public abstract class RoleBase<T> : Role where T : RoleBase<T>, new()
{
    public static List<T> players = [];       // 该类型所有实例
    public static RoleId RoleId;              // 静态 roleId

    // 初始化：注册到全局列表
    public void Init(PlayerControl player)
    {
        this.player = player;
        players.Add((T)this);
        allRoles.Add(this);
    }

    // 获取本地玩家对应的角色实例
    public static T local => players.FirstOrDefault(x => x.player == PlayerControl.LocalPlayer);

    // 检查是否存在
    public static bool exists => players.Count > 0;

    // 检查是否有存活玩家
    public static bool hasAlivePlayers => livingPlayers.Count > 0;

    // 所有玩家实例
    public static List<PlayerControl> allPlayers =>
        players.Select(x => x.player).Where(x => x != null).ToList();

    // 存活的玩家实例
    public static List<PlayerControl> livingPlayers =>
        players.Select(x => x.player).Where(x => x != null && !x.Data.IsDead).ToList();

    // 获取指定玩家的该角色实例
    public static T getRole(PlayerControl player = null)
    {
        player ??= PlayerControl.LocalPlayer;
        return players.FirstOrDefault(x => x.player == player);
    }

    // 检查玩家是否有该角色
    public static bool isRole(PlayerControl player) =>
        players.Any(x => x.player == player);

    // 设置角色（如果尚未设置）
    public static void setRole(PlayerControl player)
    {
        if (!isRole(player))
        {
            T role = new();
            role.Init(player);
            role.PostInit();
            TORGameManager.Instance?.RecordRoleHistory(player);
        }
    }

    // 擦除角色
    public static void eraseRole(PlayerControl player)
    {
        players.DoIf(x => x.player == player, x => x.ResetRole(false));
        players.RemoveAll(x => x.player == player && x.roleId == RoleId);
        allRoles.RemoveAll(x => x.player == player && x.roleId == RoleId);
        TORGameManager.Instance?.RecordRoleHistory(player);
    }

    // 交换角色（Shifter 等使用）
    public static void swapRole(PlayerControl p1, PlayerControl p2)
    {
        var index = players.FindIndex(x => x.player == p1);
        if (index >= 0)
        {
            players.DoIf(x => x.player == p1, x => x.ResetRole(true));
            players[index].player = p2;
            players.DoIf(x => x.player == p2, x => x.PostInit());
        }
    }
}
```

## 4. 如何创建新角色

### 4.1 步骤总览

1. 在 `RoleId` 枚举中添加新值
2. 创建 `Roles/YourNewRole.cs` 文件
3. 在 `RoleData.allRoleIds` 字典中注册
4. 在 `RoleInfo.cs` 中添加 `RoleInfo` 静态实例
5. 在 `TheOtherRoles.cs` 的 `clearAndReloadRoles()` 中添加清理调用
6. 在 `CustomOptionHolder.cs` 中添加选项
7. 在 `RoleAssignmentPatch.cs` 中添加分配逻辑
8. 在 `RoleInfo.allRoleInfos` 列表中添加引用
9. 在角色分类列表中添加

### 4.2 角色文件结构模板

```csharp
// Roles/YourNewRole.cs
using System.Collections.Generic;
using System.Linq;
using TheOtherRoles.Modules;
using UnityEngine;
using static TheOtherRoles.TheOtherRoles;

namespace TheOtherRoles.Roles
{
    [TORRPCHolder]  // ★ 必须：标记为 RPC 持有者，自动注册网络处理
    public class YourNewRole : RoleBase<YourNewRole>
    {
        // ─── 静态配置 ───
        public static Color color = new Color32(255, 0, 0, 255);  // 角色颜色
        public static float cooldown = 30f;                       // 技能冷却

        // ─── 实例字段 ───
        public float cooldownTimer = 0f;
        public PlayerControl currentTarget;

        // ─── 构造函数 ───
        public YourNewRole()
        {
            RoleId = roleId = RoleId.YourNewRole;  // ★ 必须：设置 roleId
            cooldownTimer = 0f;
            currentTarget = null;
        }

        // ─── 静态初始化方法 ───
        public static void clearAndReload()
        {
            cooldown = CustomOptionHolder.yourNewRoleCooldown.getFloat();
            players = [];  // ★ 必须清空列表
        }

        // ─── 重写生命周期方法 ───
        public override void PostInit()
        {
            if (PlayerControl.LocalPlayer != player) return;
            // 本地玩家初始化（创建按钮、加载Sprite等）
        }

        public override void FixedUpdate()
        {
            if (player != PlayerControl.LocalPlayer) return;
            // 每帧逻辑（仅本地执行）
            if (cooldownTimer > 0f) cooldownTimer -= Time.deltaTime;
        }

        public override void OnKill(PlayerControl target)
        {
            // 击杀回调
            cooldownTimer = cooldown;
        }

        public override void OnDeath(PlayerControl killer = null)
        {
            // 死亡回调
        }

        public override void OnMeetingStart()
        {
            // 会议开始
        }

        public override void OnMeetingEnd(PlayerControl exiled = null)
        {
            // 会议结束
        }

        public override void ResetRole(bool isShifted)
        {
            // 角色被擦除/转移
        }

        // ─── 帮助 Sprite ───
        static public IEnumerable<HelpSprite> GetHelpSprites()
        {
            yield return new(getButtonSprite(), "yourNewRoleHint");
        }

        // ─── Sprite 缓存 ───
        private static Sprite buttonSprite;
        public static Sprite getButtonSprite()
        {
            if (buttonSprite) return buttonSprite;
            buttonSprite = Helpers.loadSpriteFromResources(
                "TheOtherRoles.Resources.YourNewRoleButton.png", 115f);
            return buttonSprite;
        }
    }
}
```

### 5.5 [TORRPCHolder] 自动注册机制

标记了 `[TORRPCHolder]` 的类会被 `RemoteProcessBase.Load()` 自动扫描并注册。

```csharp
[TORRPCHolder]
public class CombinedRemoteProcess : RemoteProcessBase
{
    public static CombinedRemoteProcess CombinedRPC = new();

    CombinedRemoteProcess() : base("CombinedRPC", true) { }

    public override void Receive(MessageReader reader)
    {
        int num = reader.ReadInt32();
        for (int i = 0; i < num; i++)
            AllTORProcess[reader.ReadInt32()].Receive(reader);
    }

    public void Invoke(params RPCInvoker[] invokers)
    {
        RPCRouter.SendRpc(Name, Hash, (writer) =>
        {
            writer.Write(invokers.Count(i => !i.IsDummy));
            foreach (var invoker in invokers)
            {
                if (!invoker.IsDummy)
                    invoker.Invoke(writer);
                else
                    invoker.InvokeLocal();
            }
        }, () => { }, ShouldBeReliable);
    }
}
```

**工作原理：**
1. `RemoteProcessBase.Load()` 扫描所有标记 `[TORRPCHolder]` 的类
2. 调用其静态构造函数确保 `RemoteProcess<>` 字段初始化
3. 通过 Harmony 拦截这些字段赋值，包装成 RPC 调用

### 5.6 RPCRouter — RPC 批处理

```csharp
public static class RPCRouter
{
    // 创建一个 RPC 批处理区块
    public static RPCSection CreateSection(string label = null) => new(label);

    // 发送单个 RPC
    public static void SendRpc(string name, int hash,
        Action<MessageWriter> sender,
        Action localBodyProcess,
        bool shouldBeReliable)
    {
        if (currentSection == null)
        {
            // 直接发送
            MessageWriter writer = AmongUsClient.Instance.StartRpcImmediately(
                PlayerControl.LocalPlayer.NetId, 128,
                shouldBeReliable ? SendOption.Reliable : SendOption.None, -1);
            writer.Write(hash);
            sender.Invoke(writer);
            AmongUsClient.Instance.FinishRpcImmediately(writer);
            localBodyProcess.Invoke();
        }
        else
        {
            // 加入批处理队列
            evacuateds.Add(new RPCInvoker(hash, sender, localBodyProcess));
        }
    }
}

// 使用示例
using (RPCRouter.CreateSection("BatchOperations"))
{
    YourRpc1.Invoke(data1);
    YourRpc2.Invoke(data2);
    YourRpc3.Invoke(data3);
} // 离开 using 块时自动发送一次合并的 RPC
```

### 5.7 RPCInvoker — 可组合的 RPC

```csharp
public class RPCInvoker
{
    Action<MessageWriter> sender;
    Action localBodyProcess;
    int hash;
    public bool IsDummy { get; private set; }

    // 完整 RPC（发送 + 本地执行）
    public RPCInvoker(int hash, Action<MessageWriter> sender, Action localBodyProcess) { ... }

    // 仅本地执行
    public RPCInvoker(Action localAction)
    {
        this.hash = 0;
        this.sender = null!;
        this.localBodyProcess = localAction;
        this.IsDummy = true;
    }

    public void Invoke(MessageWriter writer) { writer.Write(hash); sender.Invoke(writer); localBodyProcess.Invoke(); }
    public void InvokeSingle() { ... }  // 仅发送网络
    public void InvokeLocal() { localBodyProcess.Invoke(); }  // 仅本地
}
```

```csharp
    {
        int completed = 0;

        }
        return (completed, total);
    }
```

## 总结

本指南涵盖了 TORV 模组开发的核心内容：

1. **角色系统** — CRTP 泛型模式，通过 `RoleBase<T>` 实现
2. **RPC 系统** — 两层架构：CustomRPC 枚举 + Reactor RemoteProcess
3. **Harmony 补丁** — 注入游戏原代码，修改行为
4. **Reactor API** — 网络同步、协程包装、类注册
5. **自定义选项** — 配置持久化、网络同步、UI 生成
6. **新模式** — 枚举扩展、选项注册、逻辑分离
